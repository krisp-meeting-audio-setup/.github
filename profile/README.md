## Troubleshooting Common Issues

Install issues? Select the virtual devices inside the meeting app, not only in the system settings.  
Performance problems? Disable other virtual audio devices that compete for the same endpoints.  
License/activation? Check the mute state before assuming suppression is broken.  
Compatibility? Restart the audio service after a driver update.  
Update failures? Reinstall the virtual driver if the device disappears from the list.
